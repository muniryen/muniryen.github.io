Developer and contact

This privacy policy applies to Güzel İzmir, provided by Münir Yenigül (mimidev).

Accounts and application data

The application is designed in such a way that it does not require any personal data to be processed, shared or hosted. Therefore, personal data is not processed, shared or hosted by the developer.

The application can be used without creating an account or requiring a login. Information required for such operations is neither collected nor shared.

Advertising and third-party services

Google Mobile Ads (AdMob) may collect and share IP addresses, advertising/app identifiers, usage interactions and diagnostics for advertising, analytics and fraud prevention. IP addresses can indicate approximate location. The data involved depends on the SDK version and configuration. Google states that Mobile Ads SDK data is encrypted in transit using TLS.

Maps and data sources

GPS service is not run and location information is not shared without the user's permission. There is no need for user location information. flutter_map plugin is only used to show the location of countries on the map. In flutter_map widget, the codes are set to not prompt the user for current location information.

The dataset source is the İzmir Open Data Portal.

acikveri.bizizmir.com

The developer has not personally checked the accuracy of the datasets. It is left to the discretion of the users.

The developer sincerely declares that he is fully dependent on the above sources and did not intentionally make any changes while transferring the information from the above sources to the application's database, and if there is any inconsistency or inaccuracy, this situation is not intentional. If you detect any mistake, please report it to makriyal@gmail.com.

Retention and deletion

You can remove app data stored on your device by clearing app storage in Android settings or uninstalling the app. Backups depend on your device backup settings. This does not delete data held by advertising providers, whose retention and deletion practices are described in their policies. There is no in-app account to delete. For information you sent by email, contact the developer to request deletion.
